Custom Phone Input & Country Selector

A lightweight, responsive, and dependency-minimal international phone input widget and country picker for modern web forms.

240+ Countries Auto GeoIP Lookup Live Search Exact Length Validation Twemoji SVG Flags

Overview

Collecting international phone numbers on web forms often causes user frustration due to ambiguous country codes, improper formatting, and invalid digit lengths.

This project provides an out-of-the-box solution using clean HTML5, CSS3, and jQuery. It automatically resolves the user's location via IP lookup, validates phone length according to country-specific telephone standards, and submits standard clean payload inputs for backend processing.

No complex build steps required. Works in vanilla HTML, PHP, Laravel, Node.js, WordPress, or any web framework without requiring Webpack, Vite, or React build tools.

Key Features

Designed with user experience, validation accuracy, and developer simplicity in mind.

240+ Countries

Complete dataset with names, dial codes, ISO2 codes, and min/max digit limits.

Auto GeoIP Detection

Preselects user's country using ipinfo.io with automatic fallback to India (+91).

Instant Filtering

Search quickly by country name, international dial code, or 2-letter ISO code.

Strict Digit Control

Automatically filters non-numeric characters and enforces national maximum length limits.

Per-Country Validation

Validates entered digits against specific minimum and maximum lengths on form submit.

Ready for Forms

Populates standard hidden inputs for direct server POST or AJAX handling.

Quickstart & Local Server

How to run the project locally without encountering CORS errors.

Important: Modern browsers block AJAX calls ($.getJSON("data/countries.json")) when opened via direct file:/// links. You must serve the folder using a local HTTP server.
Terminal Commands 
# Option A: Python 3
python -m http.server 8000

# Option B: Node.js (npx)
npx serve .

# Option C: PHP Built-in Server
php -S localhost:8000

# Option D: VS Code
# Right-click index.html -> "Open with Live Server"

Once started, visit http://localhost:8000/index.html in your browser.

1. Dynamic Phone Input (index.html)

Convert any basic input into a full-featured international phone picker with zero manual HTML overhead.

You only need to write standard form inputs in your HTML; the JavaScript automatically wraps the field and builds the flag dropdown, search bar, and error containers:

HTML Markup 
<form id="phoneForm" class="form-wrap" novalidate>
    <label for="phoneNumber">Mobile number</label>

    <!-- Simple input: widget is dynamically generated around this -->
    <input type="tel" id="phoneNumber" class="phone-number"
           placeholder="Enter mobile number" autocomplete="tel" inputmode="numeric">

    <!-- Hidden fields automatically populated for submission -->
    <input type="hidden" id="countryName" name="country_name">
    <input type="hidden" id="countryCode" name="country_code">
    <input type="hidden" id="countryIso"  name="country_iso">
    <input type="hidden" id="hiddenPhone" name="phone">
    <input type="hidden" id="fullPhone"   name="full_phone">

    <button type="submit" class="submit-btn">Submit</button>
</form>

Country JSON Schema (data/countries.json)

Every country item in data/countries.json is structured with standard properties:

JSON Structure 
{
  "name": "United States",
  "iso2": "US",
  "code": "+1",
  "flag": "https://cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f1fa-1f1f8.svg",
  "min": 10,
  "max": 10
}
Field Type Description Example
name string Official English name of the country. "United Kingdom"
iso2 string Two-letter ISO 3166-1 alpha-2 code. "GB"
code string International dialing code with "+" prefix. "+44"
flag string URL to Twemoji CDN SVG vector flag. "https://cdn.jsdelivr.net/..."
min number Minimum allowed national phone digits. 10
max number Maximum allowed national phone digits. 10

Form Submission Payload

The widget populates hidden input values on form submission so your backend receives clean, sanitized data:

Input Name Target Field Example Value Purpose
country_name #countryName "Germany" Full name of the selected country.
country_code #countryCode "+49" Calling dial code.
country_iso #countryIso "DE" ISO2 code for localization or billing.
phone #hiddenPhone "15123456789" Sanitized user digits (non-digits removed).
full_phone #fullPhone "+4915123456789" Complete international dialable number.

Backend Integration Examples

Easily handle incoming phone submissions in your server stack:

PHP Example (process.php) 
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $countryName = filter_input(INPUT_POST, 'country_name', FILTER_SANITIZE_SPECIAL_CHARS);
    $countryCode = filter_input(INPUT_POST, 'country_code', FILTER_SANITIZE_SPECIAL_CHARS);
    $phone       = filter_input(INPUT_POST, 'phone', FILTER_SANITIZE_NUMBER_INT);
    $fullPhone   = filter_input(INPUT_POST, 'full_phone', FILTER_SANITIZE_SPECIAL_CHARS);

    if (empty($phone) || empty($countryCode)) {
        http_response_code(400);
        echo json_encode(["status" => "error", "message" => "Phone number is required."]);
        exit;
    }

    // Ready for SMS verification, Twilio, or database storage
    echo json_encode([
        "status" => "success",
        "full_phone" => $fullPhone,
        "country" => $countryName
    ]);
}
?>

Customization & Geolocation Configuration

Fine-tune widget defaults, colors, and GeoIP behavior.

1. Change the Default Country

If GeoIP fails or is blocked, the widget defaults to India ("IN"). To change this to United States ("US"), update the check in js/phone-input.js or index.html:

JavaScript 
if (!selectedCountry) {
    selectedCountry = countries.find(function (country) {
        return country.iso2 && country.iso2.toUpperCase() === "US"; // Change "IN" to "US"
    }) || countries[0];
}

2. Disable GeoIP Lookup

To disable external network calls completely and instantly default to a fixed country:

JavaScript 
function geoIpLookup(success) {
    // Immediately return default country without network request
    success("US");
}

Troubleshooting & FAQ

Q: The country dropdown is empty when opening index.html directly from file explorer.

Modern browsers restrict AJAX requests to local file:/// paths. You must run the project using a local web server (e.g. VS Code Live Server, python -m http.server, or npx serve).

Q: What happens if the user's ad-blocker blocks ipinfo.io?

The code uses jQuery's .always() promise method. If the GeoIP API fails, the widget catches the error automatically and falls back safely to India (or your chosen default) without any user-facing errors.

Q: Can I use this with Bootstrap 5 or Tailwind CSS?

Yes! index-2.html is already configured with Bootstrap 5. The CSS classes use isolated names (.custom-phone, .country-dropdown) that do not conflict with Bootstrap or Tailwind utility classes.
